# Book Landing Page Work Schedule

Project: landing page for the book **The Invisible Collapse**

## Goal
Create a visually strong, elegant landing page inspired by Nitzan's final project that feels literary, modern, and polished.

## Technical Direction
- Build the page with React + Vite instead of plain HTML
- Keep Node.js only for the build/tooling layer, not as a backend unless we need one later
- Make the whole page Hebrew and right-to-left
- Use a design system that supports long-form storytelling and reusable sections

## Work Schedule

### Phase 1 — Research and Direction
- Review the reference portfolio and final project
- Identify the mood, palette, typography style, and layout patterns
- Define the core message of the landing page
- Collect imagery, textures, and visual elements that fit the book theme

### Phase 2 — Content Planning
- Write the hero headline and subtitle in Hebrew
- Prepare a short book description in Hebrew
- Decide on key sections:
  - Hero
  - About the book
  - Author or project inspiration
  - Visual gallery or concept section
  - Call to action
- Draft button text and footer text

### Phase 3 — Visual Design
- Choose a color palette that feels dramatic and refined
- Select font pairings for title and body text
- Create spacing and layout rules
- Define RTL structure and Hebrew typography behavior
- Design desktop and mobile versions
- Make sure the page feels premium and readable

### Phase 4 — Build the Page
- Set up the HTML structure
- Add the main layout and sections
- Apply styling for typography, spacing, and background effects
- Add images or decorative elements
- Make the design responsive

### Phase 5 — Polish
- Improve hover states and transitions
- Check contrast and readability
- Test on different screen sizes
- Fix alignment, spacing, and visual balance
- Remove anything unnecessary

### Phase 6 — Final Review
- Review the page as a whole
- Compare it against the reference inspiration
- Confirm the page tells a clear story
- Export or prepare for deployment

## Suggested Order
1. Research
2. Content planning
3. Wireframe
4. Visual design
5. Implementation
6. Polish
7. Final review

## Notes
- Keep the design elegant and not crowded
- Focus on atmosphere and storytelling
- Use the reference site only as inspiration, not as a copy
- Treat the page more like an editorial book experience than a generic marketing site
