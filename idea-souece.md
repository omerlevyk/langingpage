# Landing Page Idea Source

## Project Idea
A landing page for the book **The Invisible Collapse**.

The page should feel:
- elegant
- minimal
- architectural
- atmospheric
- serious and conceptual

## Main Inspiration
The inspiration comes from Nitzan Shelef Levy’s final project, **The Invisible Collapse**.
The project explores the idea of collapse as something that happens slowly beneath the surface before it becomes visible.

## Visual Direction
The landing page should reflect:
- dark and refined tones
- large typography
- wide spacing
- strong image focus
- a clean and editorial layout

## Story to Tell
The page should communicate:
- hidden tension
- gradual erosion
- memory and rupture
- architecture as a response to collapse
- a book that feels thoughtful and dramatic
